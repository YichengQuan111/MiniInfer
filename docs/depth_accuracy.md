# V1 深度精度验收

## 数据、比较口径与门槛冻结

全部输入、几何和模型来源见 [部署契约](depth_deployment.md)。16 张 DA-2K 图像按来源路径预先划为 8 张开发集、8 张最终集。Python FP32 是数值参考；人工近远标注独立于预测。结果未做缩放、平移或 min-max 对齐。

2026-10-11，ORT 开发集通过后、首次运行最终集之前，冻结 [ORT FP32 门槛](../data/depth/thresholds_ort_fp32.json)：逐元素 `atol=0.001, rtol=0.0001`，越界比例必须为零；每张图及汇总 P99 绝对误差不超过 0.001、MAE 不超过 0.0005；前后处理要求逐元素一致；排序正确率不得下降。门槛在开发集首次执行前已写入，开发结果通过，未作放宽。

统计包含逐图与按像素加权的 MAE/RMSE/最大/P99 绝对误差、非有限值数和容差越界比例；P99 使用 NumPy linear quantile。排序按有效人工点对计数，相等算错，同时约束逐图与汇总正确率。小样本检查只说明该子集中的转换和任务保持情况。

## ORT CPU FP32 开发集

8/8 张通过。前处理与后处理最大误差均为 0。原始输出 MAE `1.67194e-6`、RMSE `4.12897e-6`、最大误差 `2.87548e-4`、P99 `1.97887e-5`；还原深度最大误差 `1.30892e-4`。所有越界与非有限值计数为 0。人工排序 Python/ORT 均为 17/17。

完整逐图证据见[开发集报告](validation/v12_development.json)。

## ORT CPU FP32 最终集

8/8 张通过，冻结门槛未变。原始输出 MAE `1.88364e-6`、RMSE `4.87180e-6`、最大误差 `3.76344e-4`、P99 `2.34253e-5`；还原深度 MAE `9.77553e-7`、最大误差 `1.03712e-4`。前后处理与图像/同张量两条路径均逐元素一致，非有限值与越界数为 0。

人工排序 Python/ORT 均为 **11/13（84.62%）**，转换未新增错误；这不是模型的绝对准确率保证。逐图点对、数值和执行命令见[最终集报告](validation/v12_final.json)。
